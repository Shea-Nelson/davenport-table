What a peep name can and cannot do

A peep name is not a secure identity. Anyone who can use your browser, or anyone holding the private edit code, can change or remove that peep. The code is shown once. The board stores a hash, not the code. There is no email reset. If both this browser and the code are gone, an operator with the server admin token can remove the row. That token is never sent to the browser, and admin actions stay off until it is set in the server environment.

Any peep can change the shared heat estimate and can edit only their own games and claims. Two peeps cannot take the same bed. The claim is still only as trustworthy as the peep name.

Everyone who opens this board sees the same roster. The private edit code stays in this tab so you can change your own peep. The roster itself is not stored in the browser.

What is stored

  • Peep name, optional note, the time you joined, and arrival and departure if you set them.
  • A hash of the edit code. Not the code itself.
  • Room claims and their short notes.
  • Games you add: title, optional player counts, house note.
  • Whether the heat estimate is switched on.
  • A rate-limit counter keyed by a hash of the network address plus a server salt. The raw address is not kept.

Not stored: email, legal name, payment, or the street address of the house.

The Davenport Table keeps a shared roster, room claims, and a bring-list. The street address of the house is not published.
